One project, four stages

Native projects follow Design → PCB → Case → Export. Selection, visibility and camera carry across stages; edits save immediately while solving and outline updates run in the background.

01

Design

Place keys and components; open the Part library for reusable footprints and models. Code opens the source.

  • Enter stagger and spacing as 0.5u or 0.25v, millimetres beside the value
  • Quarter-unit snapping is the default
  • Rows and columns are editable, named objects
02

PCB

Automatic outline rebuilds managed recipes after edits; turn it off to freeze the exact contour.

  • Continuous editing: consecutive moves accumulate without waiting
  • Matrix wiring conflicts block exports, with findings that explain what needs fixing
  • Generated outline updates share the originating edit’s undo step
03

Case

Select a shell, plate, PCB, footprint group, placement or mounting feature; tree and canvas share the inspector.

  • Inspect 2D plan, assembled, exploded, section or isolated part views
  • Press Generate; review blockers and clearance checks separately
  • Automatic mounting retains pinned features
04

Export

Confirm the current geometry and download the case ZIP. Edits invalidate confirmation.

  • PCB, DXF, and 3D model files from the same source
  • Source and valid PCB exports remain available
  • Failed generation retains the last valid preview
